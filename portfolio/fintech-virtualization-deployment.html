High-Availability Fintech Virtualization Cluster in GIFT City

Executive Overview

An algorithmic trading firm operating inside the GIFT City International Financial Services Centre (IFSC) required an infrastructure overhaul. Their existing multi-vendor hypervisors suffered from intermittent micro-stutters, causing dropped market feeds during peak NSE/BSE market opening volatility.

Strict financial regulations mandated deterministic low-latency hypervisor scheduling, zero-downtime live VM migrations (vMotion), synchronous dual-site storage replication, and compliance with SEBI and IFSCA cybersecurity guidelines.

Engineered Hardware & Storage Architecture

Vassu Infotech designed and racked an enterprise-grade compute and all-flash storage cluster across dual redundant server enclosures in a Tier III data center in Gandhinagar.

COMPUTE NODES Dell Enterprise Server Nodes

Intel Xeon multi-core processors, high-capacity DDR4 ECC Registered RAM, and redundant Platinum PSUs.

ALL-FLASH STORAGE SAN HPE All-Flash SAN Array

Dual active-active storage controllers delivering high sustained read/write IOPS over high-speed Fibre Channel SAN interconnects with inline deduplication.

NETWORK FABRIC High-Speed Leaf-Spine Switching

Cisco dual top-of-rack (ToR) switches configured with Mellanox dual-port high-speed adapters per host.

VIRTUALIZATION HYPERVISOR VMware Enterprise Virtualization

Fully configured High Availability (HA), Distributed Resource Scheduler (DRS), Proactive HA, and encrypted live migrations over dedicated kernel uplinks.

Operational Results & SLA Milestones

  • High Trading Uptime: Zero unpredicted host outages during live trading hours, maintaining continuous high-availability operations.
  • Sub-Millisecond Order Routing: Direct SR-IOV network passthrough minimized order gateway virtualization overhead.
  • Rapid Disaster Recovery: Automated VM failover across hosts completes rapidly without dropping active database socket sessions.
  • 24/7 Managed AMC Support: Backed by Vassu Infotech's 4-hour on-site hardware spare replacement commitment.
